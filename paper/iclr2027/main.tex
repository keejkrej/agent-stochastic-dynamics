\begin{abstract}
A serving LLM agent is a controlled hybrid Markov process \(X=(H,M,E,C,S)\). Self-improvement, here, is self-observation of the agent's own traces followed by a licensed edit of the graph \(C\) or of the catalog pointer \(S\)---not a weight update and not extra chat. After each episode, \(\mathrm{Obs}\) types the completion. Hits wait. A completed miss with a policy or topology attractor licenses a graph mutation \(I_{\mathrm{loop}}\) (same SKU). An incomplete episode (hang, no-write, crash) licenses a gated catalog rebind \(I_{\mathrm{sku}}\). A completed miss with no identified attractor of \(C\) also licenses \(I_{\mathrm{sku}}\). We cannot train; \(I_{\mathrm{sku}}\) is a stand-in cell, not the contribution. This is not a routing paper, not a trainer, and not a \(\tau^2\) leaderboard.
\end{abstract}

\section{The framework}
\label{sec:claim}

Once an agent leaves the lab, the data it serves on is typically private: tickets, mail, an internal tool world that is not in a public scrape and that you cannot legally or practically tune against. Fitting a static kernel to a public leaderboard---benchmaxxing---does not transfer to that setting. The wrong object is \(K_{C_0}\) chosen to raise \(\mathrm{pass}^k\) on a named bench. The right object is \emph{self-improvement} as this paper uses the word: \(\mathrm{Obs}\) plus a licensed edit of graph \(C\) or catalog pointer \(S\), after deployment, from the agent's own traces. Not weights. Not a trainer. Not extra chat.

We establish a framework, with theoretical support, so that process is well-defined:
\[
\mathrm{Obs}\;\to\; I_{\mathrm{loop}}\mid I_{\mathrm{sku}}\;\to\;\mathrm{Obs},
\]
two clocks, typed noise, two coordinates. An LLM agent is a controlled hybrid Markov process. After it serves, it observes its own traces. From that observation it may apply one of two licensed edits, then serve again. Public benches remain useful as \emph{diagnostics} that this loop ran and that \(\mathrm{Obs}\) chose a coordinate. They are not the object to max, and we do not refuse them.

The process is the closed loop
\[
\text{self-observe}\;\to\;\text{self-improve}\;\to\;\text{self-observe}\;\to\;\cdots
\]
on the hybrid state \(X=(H,M,E,C,S)\) with kernel \(K_{C,S}\). A one-shot pair \((\mathrm{Obs},I)\) is one edge of that loop, not the object. A static \(\mathrm{pass}^k=1.0\) on a one-shot graph is a wait fixed point, not self-improvement. A live airline miss is a diagnostic, not a failed leaderboard attempt.

An LLM agent is usually described as a generator with tools, or as a latent diffusion, or as an MDP over memory operations. Those descriptions miss the loop. The agent \emph{reads its own traces}. \(\mathrm{Obs}\) writes a critique of the path measure---traces, first-passage proxies, and completion (hung / transfer / crash)---into structured memory \(M\). Control is the iteration
\begin{equation}
\label{eq:ctrl}
C_{n+1}\;\sim\; P^{\mathrm{ctrl}}\big(\cdot\mid C_n,\,\mathrm{Obs}(\mathrm{traces}_n)\big)
\end{equation}
on the \textbf{fast clock}. The two licensed arms that change the path measure are:
\begin{enumerate}
\item \textbf{Loop} (\(I_{\mathrm{loop}}\)). Mutate the AgentGraph / \(C\). Same \(S\). Reconcile is a deterministic map \((G,G')\mapsto\) mount / update / retain / unmount. The \emph{composition} of \(K_{C,S}\) changes in the \(C\) factor. Serving does not pause. Then serve; observe again.
\item \textbf{Catalog pointer} (\(I_{\mathrm{sku}}\)). Gated rebind of the SKU on a \textbf{slow clock}. Same \(C\). Serving continues on the current SKU. License is an incomplete episode, not price. When an eval / first-passage gate passes, mount writes \(S\) (\texttt{CatalogPointer} beside \(C\)); \texttt{n.model} stays 0731. There is no global \texttt{PhysicalNode.provider} spray. The SKU jumped iff later serving uses \(S'\). Official later-serving helpers must pass \(S\); if a caller omits the SKU argument, bound / \texttt{n.model} still win. \(S\) is a per-episode controller coordinate (\texttt{ControlledEpisode.serving}); sidecar \texttt{servingByTask} is still a process table keyed by task, not \texttt{HybridState.S} / \(X_n.S\). \texttt{batch.servingSku} is a cell log, not the lookup. We do not claim \(S\) is already \(X_n.S\). \#13/\#14 later serving typed by \(S\) remains a unit fixture. vdom-harness PR \#15 (merged) is the \(I_{\mathrm{sku}}\) ACCEPT protocol cell: fixture after + one live 0813 serve recorded the serving id. Protocol cell, not a score. Not a Pro-vs-Flash lift. \(S\) is still a per-episode controller \texttt{CatalogPointer} (vdom \#14), not \texttt{HybridState.S}. Trainer \(I_{\mathrm{weight}}\) remains unimplemented. Failed eval: no switch. \(I_{\mathrm{sku}}\) is the stand-in slow cell, not the contribution. Not \(f_\theta\). Not a trainer. Then serve; observe the new traces.
\end{enumerate}
\(\mathrm{wait}\) is the identity on \(C\) and on \(S\): a fixed point of~\eqref{eq:ctrl}. Topology is a value \citep{vdomharness}. Determinism is allocated on the fast clock; a rebind of \(S\) is gated on the slow clock.

\paragraph{Arm choice.}
\(I_{\mathrm{loop}}\) when a \emph{completed} miss is a topology or policy attractor (the \(C\) factor of \(K_{C,S}\) sits in a quasi-stationary action set; a graph mutation can leave it). \(I_{\mathrm{sku}}\) when the episode is incomplete (hung / transfer-without-writes / crash) or the miss is not an identified failure of \(C\): gated rebind of \(S\). License is incompleteness, not price. Serving stays on the current \(S\). Gated mount writes \(S\), not \texttt{n.model}. On this stack the available cell is 0731\(\to\)0813. After deployment there is no public score. See Lemma 7.9 in \texttt{paper/FRAMEWORK.md}.

\paragraph{Two artifacts.}
Theory, typed-noise kernel, experiments, and this draft live in \texttt{agent-stochastic-dynamics}. The accompanying runtime \citep{vdomharness} iterates \texttt{improveLoop} given \(\mathrm{Obs}\). Papers, blogs, GitHub, and other agents are inputs to that runtime, not the product. On this stack the slow actuator is a catalog request \texttt{0731}\(\to\)\texttt{0813} (OpenRouter, GA 2026-08-12), a cell, not a LoRA and not a trainer. A mount that never rebinds serving to 0813 is not a jump.

\paragraph{What we are not claiming.}
We use \(\tau^2\) and the 0731 traces; we do not refuse benchmarks. We refuse treating them as the object. No SOTA claim, no saturation, no ``we improve \(\tau^2\) airline.'' Not Langevin on the loop, not an SDE on a latent manifold. Not gold reservation IDs encoded as the method: a policy node encodes \emph{rules}, never task-specific identifiers. Not a measured 0813 airline \(p_{\mathrm{hit}}\) and not a Pro-vs-Flash score: we do not invent \(p_{\mathrm{hit}}(0813)\). The hang licenses \(I_{\mathrm{sku}}\) (0731\(\to\)0813). Live airline \texttt{improveLoop} still omits after. The dedicated ACCEPT cell (vdom-harness PR \#15) recorded a live 0813 serving id; that is a protocol cell, not a score. A mount that never rebinds is not a jump. Generation-SDE papers \citep{sde2408,sde2510,lgoc2605} model token generation. Memory-as-MDP papers \citep{slmv3,memcon,memento2,memp} enlarge memory actions. Reflexion and Self-Refine \citep{reflexion,selfrefine} are particular \(I_{\mathrm{loop}}\) mutations, typically one pass, without a slow-clock rebind of \(S\) and without iterating \(\mathrm{Obs}\) after that jump. The gap is the closed loop~\eqref{eq:ctrl} on a typed-noise hybrid kernel, with \(I_{\mathrm{sku}}\) rebinds of \(S\) off the fast clock, so \(C\) or \(S\) can change after deployment.

\section{Hybrid state and typed noise}
\label{sec:hybrid}

\begin{definition}[Hybrid state]
At serving step \(n\),
\[
X_n=(H_n,M_n,E_n,C_n,S_n)\in\mathcal{V}^*\times\mathcal{M}\times\mathcal{E}\times\mathcal{C}\times\mathcal{S},
\]
where \(H\) is context, \(M\) is structured memory (including \(\mathrm{Obs}\) critiques), \(E\) is the environment / tools, \(C\) is the AgentGraph plus decoding knobs, and \(S\) is the decoder pointer. \(C\) does not contain the model id. If \(S\subset C\) and both arms write \(C\), that is one idea with two names. An optional embedding \(z_n=\Pi(X_n)\) is a projection, never the state.
\end{definition}

One serving step is a composition, not a diffusion:
(i) \(a_{n+1}\sim P^{\mathrm{gen}}_C(\cdot\mid H_n,M_n)\);
(ii) \((E_{n+1},o_{n+1})\sim P^{\mathrm{env}}(\cdot\mid E_n,a_{n+1})\);
(iii) \(M_{n+1}\sim P^{\mathrm{mem}}_C(\cdot\mid M_n,H_n,a_{n+1},o_{n+1})\);
(iv) \(H_{n+1}=\mathrm{append}(H_n,a_{n+1},o_{n+1})\) (Dirac);
(v) \(C_{n+1}\sim P^{\mathrm{ctrl}}(\cdot\mid C_n,\mathrm{Obs}(\mathrm{traces}_n))\) --- \emph{iterated}, not a one-shot map.
Write \(X_{n+1}\sim K_{C,S}(\cdot\mid X_n)\). Time is discrete and event-driven. On the fast clock \(S\) is frozen. The pair is Markov on \(\mathcal{X}\) because \((C_n,S_n)\subset X_n\).

Generation factors as
\[
P^{\mathrm{gen}}(a\mid H,M,C)=\int P^{\mathrm{dec}}_C(a\mid \tilde\ell)\,P^{\mathrm{num}}(d\tilde\ell\mid f_\theta(H),C).
\]
Three channels, conditionally independent given \(X_n\):
\begin{itemize}
\item \textbf{Sampling} \(\xi^{\mathrm{samp}}\): designed decoding RNG. Vanishes as \(\tau\to 0\) with unique argmax.
\item \textbf{Numerical} \(\xi^{\mathrm{num}}\): logit perturbation \(\tilde\ell=f_\theta(H)+\varepsilon\), not white in time. A boundary layer on near-ties, not a diffusion coefficient (Lemma~\ref{lem:gap}).
\item \textbf{Environmental} \(\xi^{\mathrm{env}}\): tools, web, clocks, other agents. Discrete, heavy-tailed.
\end{itemize}

\section{The self-observe / self-improve loop}
\label{sec:obs}

\begin{definition}[Observation]
\(\mathrm{Obs}\) maps traces, first-passage proxies \((\hat\tau_S,\hat\tau_F,\hat p_{\mathrm{hit}})\), and completion (hung / transfer / crash) to a critique in \(M\):
\[
M \leftarrow M \cup \{\texttt{obs}: \mathrm{Obs}(\mathrm{traces},\hat\tau_S,\hat\tau_F,\hat p_{\mathrm{hit}},\mathrm{completion})\}.
\]
It is a statistic, not a fourth noise channel. In the runtime: \texttt{traces} plus \texttt{runBenchmark.score} plus episode completion \citep{vdomharness}. After every intervention the same operator is applied to the \emph{new} traces. Hung, transfer-to-human, and crash are first-class completions: they are not dropped from the task set and they are not scored as silent zeros.
\end{definition}

\begin{definition}[Closed loop]
\label{def:loop}
Index improvement cycles by \(t=0,1,2,\ldots\) (a subsample of the fast clock, or a wall-clock between evals). At cycle \(t\) the agent serves under \(C_t\), producing \(\mathrm{traces}_t\), a completion, and \(\mathrm{pass}^k(t)\). Then
\[
C_{t+1}\;\sim\; P^{\mathrm{ctrl}}\big(\cdot\mid C_t,\,\mathrm{Obs}(\mathrm{traces}_t)\big).
\]
Support: \(I_{\mathrm{loop}}\), \(I_{\mathrm{sku}}\) (request), gated mount of \(S\), rollback, capability mount, commit, \(\mathrm{wait}\). \(I_{\mathrm{loop}}\) writes \(C\) on the fast clock; serving does not pause. The slow request writes neither coordinate; a jump \(S\mapsto S'\) occurs only at a gated mount; serving continues on the old pointer until that gate. Then the agent serves under \((C_{t+1},S)\), \(\mathrm{Obs}\) reads \(\mathrm{traces}_{t+1}\), and the kernel is applied again. The diagram is
\[
\mathrm{traces}_t \xrightarrow{\mathrm{Obs}} M \xrightarrow{P^{\mathrm{fast}}} C_{t+1} \xrightarrow{K_{C_{t+1},S}} \mathrm{traces}_{t+1} \xrightarrow{\mathrm{Obs}} \cdots
\]
This is the process the framework names. A single before/after is one arrow, not the loop. A rising \(\mathrm{pass}^k(t)\) on \(\tau^2\) is not required for the framework to be well-defined.
\end{definition}

\begin{definition}[Two clocks]
The \textbf{fast clock} \(n\in\mathbb{N}\) is serving under \(K_{C,S}\) and the iteration~\eqref{eq:ctrl}. Sampling and environmental noise live here. \(S\) is frozen. The \textbf{slow clock} \(\sigma\in\mathbb{N}\) is a gated rebind of \(S\) at an optional time \(T_{\mathrm{adapt}}\). Serving does not block. On \(\{T_{\mathrm{adapt}}=n\}\) a gate \(g(S',\text{fixture})\in\{\mathrm{mount},\mathrm{reject}\}\) is empirical first-passage, not ``the other SKU exists.'' After a mount, \(\mathrm{Obs}\) is not done: it reads the post-jump traces and~\eqref{eq:ctrl} continues. The fast process is piecewise homogeneous between slow jumps. Not a trainer job.
\end{definition}

\begin{definition}[First passage and \(\mathrm{pass}^k(t)\)]
\label{def:passk}
Success set \(S\), failure \(F\), \(\tau_S=\inf\{n:X_n\in S\}\), \(\tau_F=\inf\{n:X_n\in F\}\), \(p_{\mathrm{hit}}=\mathbb{P}(\tau_S<\tau_F)\). Under \(k\) i.i.d.\ repeats,
\[
\mathrm{pass}^k=\mathbb{P}\big(\tau_S^{(i)}<\tau_F^{(i)}\ \forall i\le k\big)=(p_{\mathrm{hit}})^k
\]
if the repeats are independent. This is \emph{not} \(\mathrm{pass}@k\). Along the closed loop write \(\mathrm{pass}^k(t)\) at cycle \(t\). One-step differences \(\mathrm{pass}^k(t+1)-\mathrm{pass}^k(t)\) are edges of the loop, used as diagnostics that an arm fired, not as a leaderboard delta. The slow-arm mount gate reads \(\mathrm{pass}^k\) (or fixture \(\hat p_{\mathrm{hit}}\)), not a single lucky rollout and not ``0813 exists.''
\end{definition}

\paragraph{Cascade.}
TV Lipschitz of any kernel is \(\le 1\). Expansion after a one-bit memory split is visible in Hamming on prefixes. Autoregression plus memory write is typically expanding until a commit or a validator contracts.

\section{Lemmas}
\label{sec:lemmas}

\begin{lemma}[Greedy collapse]
If \(\tau=0\), the argmax of \(f_S(H)\) is unique a.s., numerical noise is absent, and env / memory / fast control are Dirac, then \(K_{C,S}(\cdot\mid x)=\delta_{\Phi(x)}\). Residual randomness is environmental or a numerical tie---or a loop in the policy, not designed noise. \(S\) is frozen.
\end{lemma}

\begin{lemma}[Gap-sensitivity]\label{lem:gap}
Let \(\Delta\ell=\ell_{(1)}-\ell_{(2)}\) and \(\tilde\ell=\ell+\varepsilon\). If \(\Delta\ell>2\|\varepsilon\|_\infty\) then \(\arg\max\tilde\ell=\arg\max\ell\). Hence \(\mathbb{P}(\mathrm{flip})\le\mathbb{P}(\Delta\ell\le 2\|\varepsilon\|_\infty)\).
\end{lemma}

\begin{lemma}[Request \(\neq\) rebind]\label{lem:spawn}
A slow-arm request writes neither \(C\) nor \(S\). While it is in flight, the serving process is Markov under the pre-request kernel \(K_{C,S}\), and~\eqref{eq:ctrl} may still apply \(I_{\mathrm{loop}}\) or \(\mathrm{wait}\) on the fast clock. A jump of \(S\) occurs only at a gated mount. After that jump, \(\mathrm{Obs}\) is applied to the new traces. Reject and rollback are the identity (resp.\ the inverse) on the jump. Not a trainer.
\end{lemma}

\begin{lemma}[Eval gate]
Mounts occur iff \(\hat p_{\mathrm{hit}}\ge\mathrm{threshold}\) on a fixture (or \(\mathrm{pass}^k\) when that is the gate). This is empirical first-passage (Definition~\ref{def:passk}), not a new objective and not a \(\tau^2\) SOTA criterion.
\end{lemma}

\begin{lemma}[Wait is a fixed point]
If \(\mathrm{Obs}(\mathrm{traces}_t)\) selects \(\mathrm{wait}\), then \(C_{t+1}=C_t\) and the fast kernel is unchanged. The closed loop idles until traces change (new tasks, a slow-clock mount, or env noise) enough for \(\mathrm{Obs}\) to leave \(\mathrm{wait}\). On a mixed batch this is per-task: wait-hit keeps \(C_0\); only miss / \(I_{\mathrm{loop}}\) receives \(C_1\). An unscoped global mount onto a wait-hit is an illegal apply.
\end{lemma}

\begin{lemma}[Arm choice]
If \(\mathrm{Obs}\) sees a topology or policy attractor (temperature-invariant action loop, first-right-then-repeat, invented policy, refused-but-required write), \(P^{\mathrm{fast}}\) licenses \(I_{\mathrm{loop}}\). If \(\mathrm{Obs}\) sees an incomplete episode (hang / transfer / crash / no-write), it licenses \(I_{\mathrm{sku}}\). If the miss completed and no attractor of \(C\) is identified, it also licenses \(I_{\mathrm{sku}}\) (unidentified \(C\); Lemma 7.9 clause 4). License for \(I_{\mathrm{sku}}\) is incompleteness or unidentified \(C\), not price. \(\mathrm{wait}\) remains the fixed point on \(\hat p_{\mathrm{hit}}=1\).
\end{lemma}

The typed map, inputs, outputs, and falsifier are Lemma 7.9 in \texttt{paper/FRAMEWORK.md} (Proposition 7.8a is why two arms exist). \(I_{\mathrm{sku}}\) is a gated rebind of \(S\) (on this stack, catalog \(0731\to 0813\)); serving continues on the current pointer; mount writes \(S\), not \texttt{n.model} / a global \texttt{PhysicalNode.provider}. Catalog rebind is the implemented actuator, not the title claim. \(S\) jumped iff later serving uses \(S'\). Negative traces are evidence for that rule, not scores to max: self-obs \(39+44\) \(0.5\to 0.0\) (wait-hit overwritten; \(C\) moved); post-gate hang on \(44\) licenses the slow arm; extra \(H\) is not \(I_{\mathrm{loop}}\). See \texttt{paper/NOTES\_ARM\_CHOICE.md}.

Proofs of the first two are elementary. Lemma~\ref{lem:spawn} is by construction of the slow request. Further tradeoffs: \texttt{paper/FRAMEWORK.md}. Counts that \emph{license} an arm---not a leaderboard---are in \texttt{paper/ANALYSIS.md}.

\subsection{Protocol}
\label{sec:protocol}

\begin{enumerate}
\item \textbf{Start naive.} Mount a one-shot AgentGraph \(C_0\) (\texttt{oneShotGraph} / \texttt{technique: one-shot}).
\item \textbf{Cycle \(t=0,1,\ldots,T\).} Serve on a slice. Record traces, completion (hung / transfer / crash), and \(\mathrm{pass}^k(t)\) from official \texttt{compute\_metrics} when \(\tau^2\) is the diagnostic. Write \(\mathrm{traces}_t\) into \(M\).
\item \textbf{\(\mathrm{Obs}(\mathrm{traces}_t)\).} Repeat rate, timeout, zero progress, tool failures, knowledge-miss, hung / transfer / crash, \(\hat p_{\mathrm{hit}}\).
\item \textbf{\(P^{\mathrm{fast}}\).} \(I_{\mathrm{loop}}\) if a completed miss is a topology or policy attractor; \(I_{\mathrm{sku}}\) (gated rebind of \(S\)) if the episode is incomplete or the miss is not an identified failure of \(C\); \(\mathrm{wait}\) (fixed point) if \(\hat p_{\mathrm{hit}}=1\). License for the slow arm is incompleteness, not price. Serving does not block on the request. Serving does not pause on \(I_{\mathrm{loop}}\).
\item \textbf{Do not stop after one intervention.} Serve under \(C_{t+1}\). \(\mathrm{Obs}\) reads the new traces. Repeat from (2).
\end{enumerate}

Implementation: \url{https://github.com/keejkrej/vdom-harness}. \texttt{improveLoop} already iterates given \(\mathrm{Obs}\) (\texttt{maxIters}). Official \(\tau^2\) owns domains, tools, user simulator, and \(\mathrm{pass}^k\). \texttt{python -m tau2\_vdom} registers \texttt{--agent vdom}. Copy official \texttt{compute\_metrics} per cycle. Do not invent \(\mathrm{pass}^k(t)\). Do not encode gold reservation IDs as the method.

\section{Discussion}

The contribution is the framework and the theory---two licensed edits, typed \(\mathrm{Obs}\). Hybrid state \(X=(H,M,E,C,S)\), kernel \(K_{C,S}\), three typed noise channels, \(\mathrm{Obs}\) (traces + first-passage proxies + hung / transfer / crash), and an arm-choice rule. \(I_{\mathrm{loop}}\) writes \(C\). The slow arm gated-rebinds \(S\). Catalog rebind is the implemented actuator, not the title. \(\tau^2\) and the 0731 traces remain diagnostics that the loop exists and that \(\mathrm{Obs}\) can pick a coordinate, not a bench to max.

The 0731 toys license \(I_{\mathrm{loop}}\) on sequential-tool attractors. Held-out airline is the eval: one policy-checklist \(I_{\mathrm{loop}}\) moved \(p_{\mathrm{hit}}\) \(0.7\to 0.9\) at \(k=1\), including a regression on a task the one-shot already hit. That is better than the one-shot control on this \(10\times 1\) slice. It is not a reliability claim. The loop is real (\(\mathrm{Obs}\) fired, \(C\) mutated, serving did not pause). The \emph{content} of \(C\) is not self-reflection: \(\mathrm{Obs}\) selected a canned node we authored after reading \(39/44\) gold. The discovery slice is a test-hacking risk. Held-out is weak generalization of that prior, including a regression on a task \(\mathrm{Obs}\) had marked \texttt{wait}. Not saturation, and not a \(\tau^2\) win. Benchmaxxing on \(39/41/44\) does not transfer; a 3-trial replication there is secondary (\(\mathrm{pass}^3\) stays \(0.333\)). The earlier \(0.333\to 0.667\) was \(n=1\) on that overfit slice. A later self-obs run on \(39+44\) (\(0.5\to 0.0\); \S\ref{sec:selfobs}) is the same diagnostic shape: the loop ran, \(\mathrm{Obs}\) chose \(I_{\mathrm{loop}}\) on the self path, and an unscoped global \(C\) change onto a wait-hit is an illegal apply---not a SOTA miss. Apply is now scoped (wait-hit keeps \(C_0\)). Remaining transfers license \(I_{\mathrm{sku}}\). The five-task retail \(1.0\) is \(\mathbb{P}_{C_0}\) at a \(\mathrm{wait}\) fixed point. The mock \(0\to 0.5\to 1.0\) is a protocol unit test. None of these is a \(\tau^2\) SOTA claim.

In the accompanying runtime \citep{vdomharness}, \texttt{improveLoop} already iterates. The controller log is five citations: vdom-harness PR \#11 (typed \(\mathrm{Obs}\), hung-first, 39 \(I_{\mathrm{loop}}\) / 44 \(I_{\mathrm{sku}}\) / \texttt{waitKept} empty); PR \#12 (live hung-44 reject); PR \#13 (merged: a \texttt{CatalogPointer} beside \(C\); later serving typed by \(S\) for mixed 39/44); PR \#14 (merged: \(S\) is a per-episode controller coordinate, \texttt{ControlledEpisode.serving}; a fresh 39-only batch after mixed mount stays 0731 and does not inherit leftover \texttt{servingSku}=0813); PR \#15 (merged: \(I_{\mathrm{sku}}\) ACCEPT protocol cell; fixture after + live 0813 serve recorded the serving id; \texttt{eval/tau2/improve-live-0731-isku-44-mount.json}; \texttt{servingPaused=false}, \texttt{gate.action=mount}, \texttt{jumped=true}, \texttt{servingModelAfter=deepseek/deepseek-v4-pro-0813}). After fixture mount, \texttt{providerForNode(solve)} is 0731 on 39 and 0813 on 44. We do not claim \(S\) is already \(X_n.S\) / \texttt{HybridState.S}. \#13 closed \texttt{n.model}; \#14 closed process \texttt{servingSku} as the lookup. Remaining identification: sidecar \texttt{servingByTask} is a process table keyed by task, not \texttt{HybridState.S}. \texttt{batch.servingSku} is a cell log, not the lookup. Not a live dump. Not a trainer. \#13/\#14 later serving typed by \(S\) remains a unit fixture. PR \#15 is a protocol cell, not a score and not a Pro-vs-Flash lift. Trainer \(I_{\mathrm{weight}}\) remains unimplemented. Live airline \texttt{improveLoop} still omits after. Papers, blogs, GitHub, and other agents remain inputs, not the product.

\section{Conclusion}

A static kernel fitted to a public leaderboard is the wrong object once the agent is deployed on private data. Self-improvement, here, is \(\mathrm{Obs}\) plus a licensed edit of \(C\) or \(S\), not weights. An LLM agent is a controlled hybrid Markov process \(X=(H,M,E,C,S)\) with kernel \(K_{C,S}\). Two licensed edits: \(I_{\mathrm{loop}}\) mutates \(C\); \(I_{\mathrm{sku}}\) gated-rebinds the catalog pointer. License for \(I_{\mathrm{sku}}\) is an incomplete episode or a completed miss with no identified attractor of \(C\), not price. The typed rule is Lemma 7.9 in \texttt{paper/FRAMEWORK.md}. The controller log is vdom-harness PR \#11, PR \#12, PR \#13, PR \#14, and PR \#15 (merged). PR \#13 stores a \texttt{CatalogPointer} beside \(C\); \texttt{n.model} stays 0731. Later serving is typed by \(S\) for mixed 39/44. PR \#14 makes \(S\) a per-episode controller coordinate (\texttt{ControlledEpisode.serving}). A fresh 39-only batch after mixed mount stays 0731 and does not inherit leftover \texttt{servingSku}=0813. PR \#15 is the \(I_{\mathrm{sku}}\) ACCEPT protocol cell: fixture after + live 0813 serve recorded the serving id. Protocol cell, not a score. Not a Pro-vs-Flash lift. We do not claim \(S\) is already \(X_n.S\) / \texttt{HybridState.S}. Sidecar \texttt{servingByTask} is still a process table keyed by task. Trainer \(I_{\mathrm{weight}}\) remains unimplemented. If a mount never rebinds serving to 0813, there was no jump. We do not claim SOTA or a measured catalog win.
