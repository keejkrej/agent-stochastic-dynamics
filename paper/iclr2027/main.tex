\begin{abstract}
This paper establishes a \emph{runtime self-improvement framework with theoretical support}. It is not a \(\tau^2\)-bench leaderboard paper, and we do not claim SOTA, a live \(p_{\mathrm{hit}}\) win, or a measured weight update. An LLM agent is a controlled hybrid Markov process on state \(X=(H,M,E,C)\) with kernel \(K_C\) and three typed noise channels (sampling, numerical, environmental). Self-observation \(\mathrm{Obs}\) maps traces, first-passage proxies, and completion (hung / transfer / crash) into memory \(M\). Two licensed interventions follow. \(I_{\mathrm{loop}}\) mutates the AgentGraph / \(C\) while serving does not pause. \(I_{\mathrm{weight}}\) dispatches an asynchronous trainer on a slow clock; serving continues on the old weights until a gated \(\theta\) swap. Arm choice: \(I_{\mathrm{loop}}\) when the miss is a topology or policy attractor; \(I_{\mathrm{weight}}\) when the model does not complete tasks at all---the original reason \(\tau^2\)-bench exists. \(\tau^2\) and the 0731 rollouts are diagnostics that the loop ran and that \(\mathrm{Obs}\) chose an arm. Honest live airline \(39/44/41\): one-shot \(p_{\mathrm{hit}}=0.333\); generic \(I_{\mathrm{loop}}\) \(0.333\to 0\to 0.333\); policy-checklist \(0.333\to 0\); task 39 still misses MSJ4OA; 44 transfers with zero upgrades; 41 hangs or errors. Those numbers license \(I_{\mathrm{weight}}\); they are not a failed \(\tau^2\) attempt. A mock closed loop \(0\to 0.5\to 1.0\) on \texttt{update\_task\_1} / \texttt{impossible\_task\_1} is a protocol unit test, not an ICLR result. Static retail \(5\times 4\) \(\mathrm{pass}^k=1\) is \(\mathbb{P}_{C_0}\) at a \(\mathrm{wait}\) fixed point, not self-improvement. The trainer in the accompanying runtime is a protocol stub (\texttt{FakeTrainer}).
\end{abstract}

\section{The framework}
\label{sec:claim}

The contribution is a \emph{runtime self-improvement framework} and the hybrid-process theory that supports it. An LLM agent is a controlled hybrid Markov process. After it serves, it observes its own traces. From that observation it may apply one of two licensed interventions, then serve again. Experiments exist to show that this loop can run and that \(\mathrm{Obs}\) can choose an arm. They do not exist to raise a \(\tau^2\) score.

The process is a closed loop
\[
\text{self-observe}\;\to\;\text{self-improve}\;\to\;\text{self-observe}\;\to\;\cdots
\]
on the hybrid state \(X=(H,M,E,C)\) with kernel \(K_C\). A one-shot pair \((\mathrm{Obs},I)\) is one edge of that loop, not the object. A static \(\mathrm{pass}^k=1.0\) on a one-shot graph is not the object. A live airline miss is not a failed leaderboard attempt.

An LLM agent is usually described as a generator with tools, or as a latent diffusion, or as an MDP over memory operations. Those descriptions miss the loop. The agent \emph{reads its own traces}. \(\mathrm{Obs}\) writes a critique of the path measure---traces, first-passage proxies, and completion (hung / transfer / crash)---into structured memory \(M\). Control is the iteration
\begin{equation}
\label{eq:ctrl}
C_{n+1}\;\sim\; P^{\mathrm{ctrl}}\big(\cdot\mid C_n,\,\mathrm{Obs}(\mathrm{traces}_n)\big)
\end{equation}
on the \textbf{fast clock}. The two licensed arms that change the path measure are:
\begin{enumerate}
\item \textbf{Loop} (\(I_{\mathrm{loop}}\)). Mutate the AgentGraph / \(C\). Reconcile is a deterministic map \((G,G')\mapsto\) mount / update / retain / unmount. The \emph{composition} of \(K\) changes: critics, refiners, validators, policy checklists. \(f_\theta\) does not. Serving does not pause. Then serve; observe again.
\item \textbf{Weights} (\(I_{\mathrm{weight}}\)). Dispatch an asynchronous trainer on a \textbf{slow clock}. Serving continues on the old \(f_\theta\). When the artifact is ready and an eval gate passes, reconcile rebinds \texttt{PhysicalNode.provider}: a gated \(\theta\) swap. Failed eval: no switch. Later regression: unmount. Then serve; observe the new traces; \(P^{\mathrm{ctrl}}\) may fire again.
\end{enumerate}
\(\mathrm{wait}\) is the identity on \(C\): a fixed point of~\eqref{eq:ctrl}. Topology is a value \citep{vdomharness}. Determinism is allocated on the fast clock; learning is gated on the slow clock.

\paragraph{Arm choice.}
\(I_{\mathrm{loop}}\) when the miss is a topology or policy attractor (the composition of \(K_C\) sits in a quasi-stationary action set; a graph mutation can leave it). \(I_{\mathrm{weight}}\) is reserved for when the model does not complete tasks at all---the original reason \(\tau^2\)-bench exists. A policy-checklist that still misses the required database writes is evidence for licensing \(I_{\mathrm{weight}}\), not a reason to keep mutating topology until a leaderboard moves.

\paragraph{Two artifacts.}
Theory, typed-noise kernel, experiments, and this draft live in \texttt{agent-stochastic-dynamics}. The accompanying runtime \citep{vdomharness} iterates \texttt{improveLoop} given \(\mathrm{Obs}\). Papers, blogs, GitHub, and other agents are inputs to that runtime, not the product. The \(I_{\mathrm{weight}}\) trainer shipped with the runtime is \texttt{FakeTrainer}: a protocol demo of spawn / gate / mount / rollback. It is not a measured LoRA or HF-Jobs update.

\paragraph{What we are not claiming.}
Not SOTA on \(\tau^2\). Not a live \(p_{\mathrm{hit}}\) win on airline. Not that we ``improve \(\tau^2\) airline.'' Not Langevin on the loop, not an SDE on a latent manifold. Not gold reservation IDs (e.g.\ MSJ4OA) encoded as the method: a policy node encodes \emph{rules}, never task-specific identifiers. Not that \(I_{\mathrm{weight}}\) has been measured: only the two-clock protocol and a trainer stub exist. Generation-SDE papers \citep{sde2408,sde2510,lgoc2605} model token generation. Memory-as-MDP papers \citep{slmv3,memcon,memento2,memp} enlarge memory actions. Reflexion and Self-Refine \citep{reflexion,selfrefine} are particular \(I_{\mathrm{loop}}\) mutations, typically one pass, without weight updates and without iterating \(\mathrm{Obs}\) after a slow-clock jump. The gap is the closed loop~\eqref{eq:ctrl} on a typed-noise hybrid kernel, with \(I_{\mathrm{weight}}\) jumps off the fast clock.

\section{Hybrid state and typed noise}
\label{sec:hybrid}

\begin{definition}[Hybrid state]
At serving step \(n\),
\[
X_n=(H_n,M_n,E_n,C_n)\in\mathcal{V}^*\times\mathcal{M}\times\mathcal{E}\times\mathcal{C},
\]
where \(H\) is context, \(M\) is structured memory (including \(\mathrm{Obs}\) critiques), \(E\) is the environment / tools, and \(C\) is the AgentGraph plus decoding knobs and bound model / adapter ids. An optional embedding \(z_n=\Pi(X_n)\) is a projection, never the state.
\end{definition}

One serving step is a composition, not a diffusion:
(i) \(a_{n+1}\sim P^{\mathrm{gen}}_C(\cdot\mid H_n,M_n)\);
(ii) \((E_{n+1},o_{n+1})\sim P^{\mathrm{env}}(\cdot\mid E_n,a_{n+1})\);
(iii) \(M_{n+1}\sim P^{\mathrm{mem}}_C(\cdot\mid M_n,H_n,a_{n+1},o_{n+1})\);
(iv) \(H_{n+1}=\mathrm{append}(H_n,a_{n+1},o_{n+1})\) (Dirac);
(v) \(C_{n+1}\sim P^{\mathrm{ctrl}}(\cdot\mid C_n,\mathrm{Obs}(\mathrm{traces}_n))\) --- \emph{iterated}, not a one-shot map.
Write \(X_{n+1}\sim K_C(\cdot\mid X_n)\). Time is discrete and event-driven. The pair \((X_n)\) is Markov on \(\mathcal{X}\) because \(C_n\subset X_n\).

Generation factors as
\[
P^{\mathrm{gen}}(a\mid H,M,C)=\int P^{\mathrm{dec}}_C(a\mid \tilde\ell)\,P^{\mathrm{num}}(d\tilde\ell\mid f_\theta(H),C).
\]
Three channels, conditionally independent given \(X_n\):
\begin{itemize}
\item \textbf{Sampling} \(\xi^{\mathrm{samp}}\): designed decoding RNG. Vanishes as \(\tau\to 0\) with unique argmax.
\item \textbf{Numerical} \(\xi^{\mathrm{num}}\): logit perturbation \(\tilde\ell=f_\theta(H)+\varepsilon\), not white in time. A boundary layer on near-ties, not a diffusion coefficient (Lemma~\ref{lem:gap}).
\item \textbf{Environmental} \(\xi^{\mathrm{env}}\): tools, web, clocks, other agents. Discrete, heavy-tailed.
\end{itemize}

\section{The self-observe / self-improve loop}
\label{sec:obs}

\begin{definition}[Observation]
\(\mathrm{Obs}\) maps traces, first-passage proxies \((\hat\tau_S,\hat\tau_F,\hat p_{\mathrm{hit}})\), and completion (hung / transfer / crash) to a critique in \(M\):
\[
M \leftarrow M \cup \{\texttt{obs}: \mathrm{Obs}(\mathrm{traces},\hat\tau_S,\hat\tau_F,\hat p_{\mathrm{hit}},\mathrm{completion})\}.
\]
It is a statistic, not a fourth noise channel. In the runtime: \texttt{traces} plus \texttt{runBenchmark.score} plus episode completion \citep{vdomharness}. After every intervention the same operator is applied to the \emph{new} traces. Hung, transfer-to-human, and crash are first-class completions: they are not dropped from the task set and they are not scored as silent zeros.
\end{definition}

\begin{definition}[Closed loop]
\label{def:loop}
Index improvement cycles by \(t=0,1,2,\ldots\) (a subsample of the fast clock, or a wall-clock between evals). At cycle \(t\) the agent serves under \(C_t\), producing \(\mathrm{traces}_t\), a completion, and \(\mathrm{pass}^k(t)\). Then
\[
C_{t+1}\;\sim\; P^{\mathrm{ctrl}}\big(\cdot\mid C_t,\,\mathrm{Obs}(\mathrm{traces}_t)\big).
\]
Support: \(I_{\mathrm{loop}}\), \(I_{\mathrm{weight}}\) (spawn), gated mount, rollback, capability mount, commit, \(\mathrm{wait}\). \(I_{\mathrm{loop}}\) changes the composition of \(K\) on the fast clock; serving does not pause. \(I_{\mathrm{weight}}\) spawn does not mutate \(C\); a jump \(f_\theta\mapsto f_{\theta'}\) occurs only at a gated mount on the slow clock; serving continues on the old weights until that gate. Then the agent serves under \(C_{t+1}\), \(\mathrm{Obs}\) reads \(\mathrm{traces}_{t+1}\), and the kernel is applied again. The diagram is
\[
\mathrm{traces}_t \xrightarrow{\mathrm{Obs}} M \xrightarrow{P^{\mathrm{ctrl}}} C_{t+1} \xrightarrow{K_{C_{t+1}}} \mathrm{traces}_{t+1} \xrightarrow{\mathrm{Obs}} \cdots
\]
This is the process the framework names. A single before/after is one arrow, not the loop. A rising \(\mathrm{pass}^k(t)\) on \(\tau^2\) is not required for the framework to be well-defined.
\end{definition}

\begin{definition}[Two clocks]
The \textbf{fast clock} \(n\in\mathbb{N}\) is serving under \(K_C\) and the iteration~\eqref{eq:ctrl}. Sampling and environmental noise live here. \(\theta\) is frozen until a slow jump. The \textbf{slow clock} \(\sigma\in\mathbb{N}\) is trainer jobs. Job \(\sigma\) consumes traces and returns an artifact \(A_\sigma\) at an optional time \(T_{\mathrm{adapt}}\). Serving does not block. On \(\{T_{\mathrm{adapt}}=n\}\) a gate \(g(A_\sigma,\text{fixture})\in\{\mathrm{mount},\mathrm{reject}\}\) is an empirical first-passage test. After a mount, \(\mathrm{Obs}\) is not done: it reads the post-jump traces and~\eqref{eq:ctrl} continues. The fast process is piecewise homogeneous between slow jumps.
\end{definition}

\begin{definition}[First passage and \(\mathrm{pass}^k(t)\)]
\label{def:passk}
Success set \(S\), failure \(F\), \(\tau_S=\inf\{n:X_n\in S\}\), \(\tau_F=\inf\{n:X_n\in F\}\), \(p_{\mathrm{hit}}=\mathbb{P}(\tau_S<\tau_F)\). Under \(k\) i.i.d.\ repeats,
\[
\mathrm{pass}^k=\mathbb{P}\big(\tau_S^{(i)}<\tau_F^{(i)}\ \forall i\le k\big)=(p_{\mathrm{hit}})^k
\]
if the repeats are independent. This is \emph{not} \(\mathrm{pass}@k\). Along the closed loop write \(\mathrm{pass}^k(t)\) at cycle \(t\). One-step differences \(\mathrm{pass}^k(t+1)-\mathrm{pass}^k(t)\) are edges of the loop, used as diagnostics that an arm fired, not as a leaderboard delta. The \(I_{\mathrm{weight}}\) mount gate reads \(\mathrm{pass}^k\) (or fixture \(\hat p_{\mathrm{hit}}\)), not a single lucky rollout.
\end{definition}

\paragraph{Cascade.}
TV Lipschitz of any kernel is \(\le 1\). Expansion after a one-bit memory split is visible in Hamming on prefixes. Autoregression plus memory write is typically expanding until a commit or a validator contracts.

\section{Lemmas}
\label{sec:lemmas}

\begin{lemma}[Greedy collapse]
If \(\tau=0\), the argmax of \(f_\theta(H)\) is unique a.s., numerical noise is absent, and env / memory / control are Dirac, then \(K_C(\cdot\mid x)=\delta_{\Phi(x)}\). Residual randomness is environmental or a numerical tie---or a loop in the policy, not designed noise.
\end{lemma}

\begin{lemma}[Gap-sensitivity]\label{lem:gap}
Let \(\Delta\ell=\ell_{(1)}-\ell_{(2)}\) and \(\tilde\ell=\ell+\varepsilon\). If \(\Delta\ell>2\|\varepsilon\|_\infty\) then \(\arg\max\tilde\ell=\arg\max\ell\). Hence \(\mathbb{P}(\mathrm{flip})\le\mathbb{P}(\Delta\ell\le 2\|\varepsilon\|_\infty)\).
\end{lemma}

\begin{lemma}[Spawn \(\neq\) mount]\label{lem:spawn}
Spawning a trainer does not mutate \(C\). While the job runs, the serving process is Markov under the pre-job kernel \(K_C\), and~\eqref{eq:ctrl} may still apply \(I_{\mathrm{loop}}\) or \(\mathrm{wait}\) on the fast clock. A jump in \(f_\theta\) occurs only at a gated mount. After that jump, \(\mathrm{Obs}\) is applied to the new traces. Reject and rollback are the identity (resp.\ the inverse) on the jump.
\end{lemma}

\begin{lemma}[Eval gate]
Mounts occur iff \(\hat p_{\mathrm{hit}}\ge\mathrm{threshold}\) on a fixture (or \(\mathrm{pass}^k\) when that is the gate). This is empirical first-passage (Definition~\ref{def:passk}), not a new objective and not a \(\tau^2\) SOTA criterion.
\end{lemma}

\begin{lemma}[Wait is a fixed point]
If \(\mathrm{Obs}(\mathrm{traces}_t)\) selects \(\mathrm{wait}\), then \(C_{t+1}=C_t\) and the fast kernel is unchanged. The closed loop idles until traces change (new tasks, a slow-clock mount, or env noise) enough for \(\mathrm{Obs}\) to leave \(\mathrm{wait}\).
\end{lemma}

\begin{lemma}[Arm choice]
If \(\mathrm{Obs}\) sees a topology or policy attractor (temperature-invariant action loop, first-right-then-repeat, invented policy, refused-but-required write), \(P^{\mathrm{ctrl}}\) licenses \(I_{\mathrm{loop}}\). If \(\mathrm{Obs}\) sees that the model does not complete the task at all (knowledge miss, empty retrieval, hang / transfer / crash with no progress in \(E\) after licensed \(I_{\mathrm{loop}}\)), \(P^{\mathrm{ctrl}}\) licenses \(I_{\mathrm{weight}}\). \(\mathrm{wait}\) remains the fixed point on \(\hat p_{\mathrm{hit}}=1\).
\end{lemma}

Proofs of the first two are elementary. Lemma~\ref{lem:spawn} is by construction of \(I_{\mathrm{weight}}\). Further tradeoffs: \texttt{paper/FRAMEWORK.md}. Counts that \emph{license} an arm---not a leaderboard---are in \texttt{paper/ANALYSIS.md}.

\section{Diagnostics: existence and arm choice}
\label{sec:result}

No private corpus. Live sampling, when keyed, uses OpenRouter and \texttt{deepseek/deepseek-v4-flash-0731} only. We do not invent \(\tau^2\) scores. We do not claim SOTA. We do not claim a live \(p_{\mathrm{hit}}\) win.

The object of this section is \emph{existence} of the loop and \emph{arm choice} by \(\mathrm{Obs}\). \(\tau^2\) and the 0731 rollouts are diagnostics that the loop ran and that \(\mathrm{Obs}\) chose an arm. They are not an ICLR leaderboard and they are not the contribution.

\subsection{Protocol}
\label{sec:protocol}

\begin{enumerate}
\item \textbf{Start naive.} Mount a one-shot AgentGraph \(C_0\) (\texttt{oneShotGraph} / \texttt{technique: one-shot}).
\item \textbf{Cycle \(t=0,1,\ldots,T\).} Serve on a slice. Record traces, completion (hung / transfer / crash), and \(\mathrm{pass}^k(t)\) from official \texttt{compute\_metrics} when \(\tau^2\) is the diagnostic. Write \(\mathrm{traces}_t\) into \(M\).
\item \textbf{\(\mathrm{Obs}(\mathrm{traces}_t)\).} Repeat rate, timeout, zero progress, tool failures, knowledge-miss, hung / transfer / crash, \(\hat p_{\mathrm{hit}}\).
\item \textbf{\(P^{\mathrm{ctrl}}\).} \(I_{\mathrm{loop}}\) if the miss is a topology or policy attractor; \(I_{\mathrm{weight}}\) (spawn; later gated mount) if the model does not complete tasks at all; \(\mathrm{wait}\) (fixed point) if \(\hat p_{\mathrm{hit}}=1\). Serving does not block on the trainer. Serving does not pause on \(I_{\mathrm{loop}}\).
\item \textbf{Do not stop after one intervention.} Serve under \(C_{t+1}\). \(\mathrm{Obs}\) reads the new traces. Repeat from (2).
\end{enumerate}

Implementation: \url{https://github.com/keejkrej/vdom-harness}. \texttt{improveLoop} already iterates given \(\mathrm{Obs}\) (\texttt{maxIters}). Official \(\tau^2\) owns domains, tools, user simulator, and \(\mathrm{pass}^k\). \texttt{python -m tau2\_vdom} registers \texttt{--agent vdom}. Copy official \texttt{compute\_metrics} per cycle. Do not invent \(\mathrm{pass}^k(t)\). Do not encode gold reservation IDs as the method.

\subsection{\(I_{\mathrm{weight}}\) protocol (not a measured update)}
\label{sec:iweight}

Only the protocol and the two clocks are claimed. Spawn does not mutate \(C\) (Lemma~\ref{lem:spawn}). The fast process keeps \(K_C\) and the old \(f_\theta\). A slow-clock job returns an artifact; a gate reads fixture \(\hat p_{\mathrm{hit}}\) (or \(\mathrm{pass}^k\)); mount is a jump; reject and rollback are the identity and the inverse. The accompanying runtime implements this with \texttt{FakeTrainer}: a trainer stub that registers a deterministic adapted provider. That is a protocol demo, not a LoRA, not an HF Job, and not evidence that \(I_{\mathrm{weight}}\) raised any live \(p_{\mathrm{hit}}\). We do not treat the stub as a measured weight update.

\subsection{Mock closed loop is a protocol unit test}
\label{sec:mock}

On official mock tasks \texttt{update\_task\_1} / \texttt{impossible\_task\_1}, no API key, deterministic evaluator: \(p_{\mathrm{hit}}\) goes \(0\to 0.5\to 1.0\) under two \(I_{\mathrm{loop}}\) rounds (Self-Refine then validator). It is a \emph{protocol unit test}. It is not an ICLR result.

\subsection{Static retail \(5\times 4\) is \(\mathbb{P}_{C_0}\) at a wait fixed point}
\label{sec:static}

No larger \(\tau^2\) table invented.

Full trajectories: vdom-harness \texttt{eval/tau2/retail-live-20260819T083613Z.json} (same bytes as \texttt{latest.json}; 20 sims; generated 2026-08-19 10:36 CEST). Definitions applied, with real counts, in \texttt{paper/ANALYSIS\_STATIC\_TAU2.md}.

This run is a \emph{fixed} one-shot graph \(C_0\) (\texttt{tau2-oneshot}, single \texttt{solve} node). \(P^{\mathrm{ctrl}}=\mathrm{wait}\) on all 20 trials. Fast clock only. No \(I_{\mathrm{loop}}\), no \(I_{\mathrm{weight}}\). The path measure is \(\mathbb{P}_{C_0}\), not the closed loop of Definition~\ref{def:loop}. Mean (median) event-time \(\tau_S\) is \(14.8\) (\(14.5\)) actions. Consecutive same-name tools occur as catalog lookups of distinct ids; consecutive same tool+args occur \(0/155\). Logged \(\mathrm{Obs}\) critique is \texttt{path measure hits S; wait} on \(20/20\). That is why a \(1.0\) one-shot cannot demonstrate self-improvement: \(P^{\mathrm{ctrl}}\) has no license to fire. Tasks \(0\)--\(4\) of \(114\). This is a wait fixed point, not self-improvement, and not a lead number.

\section{Discussion}

The contribution is the framework and the theory: hybrid state \(X=(H,M,E,C)\), kernel \(K_C\), three typed noise channels, \(\mathrm{Obs}\) (traces + first-passage proxies + hung / transfer / crash), two licensed interventions on two clocks, and an arm-choice rule. Everything else is a diagnostic that the loop exists and that \(\mathrm{Obs}\) can pick an arm.

The 0731 toys license \(I_{\mathrm{loop}}\) on sequential-tool attractors. The live airline \(39/44/41\) numbers---including the negative generic and policy-checklist \(I_{\mathrm{loop}}\)---license \(I_{\mathrm{weight}}\) because the model does not complete those tasks. The five-task retail \(1.0\) is \(\mathbb{P}_{C_0}\) at a \(\mathrm{wait}\) fixed point. The mock \(0\to 0.5\to 1.0\) is a protocol unit test. None of these is a \(\tau^2\) SOTA claim.

In the accompanying runtime \citep{vdomharness}, \texttt{improveLoop} already iterates. Keep \(\mathrm{Obs}\) a first-class memory write after every cycle, including after a gated mount. Keep the trainer out-of-process. Label \texttt{FakeTrainer} as a protocol demo until a real slow-clock job exists. Papers, blogs, GitHub, and other agents remain inputs, not the product.

\section{Conclusion}

We established a runtime self-improvement framework with theoretical support. An LLM agent is a controlled hybrid Markov process \(X=(H,M,E,C)\) with kernel \(K_C\) and three typed noise channels. \(\mathrm{Obs}\) writes traces, first-passage proxies, and completion (hung / transfer / crash) into \(M\). \(I_{\mathrm{loop}}\) mutates \(C\) without pausing serving. \(I_{\mathrm{weight}}\) is an async trainer on a slow clock with a gated \(\theta\) swap; serving continues on the old weights. Arm choice: \(I_{\mathrm{loop}}\) for topology / policy attractors; \(I_{\mathrm{weight}}\) when the model does not complete tasks at all. \(\tau^2\) and the 0731 rollouts diagnose that the loop ran and that \(\mathrm{Obs}\) chose an arm. Honest negative \(I_{\mathrm{loop}}\) on live airline \(39/44/41\) licenses \(I_{\mathrm{weight}}\). The mock closed loop is a unit test. Static retail \(\mathrm{pass}^k=1\) is a wait fixed point. \texttt{FakeTrainer} is a protocol stub. We do not claim SOTA, a live \(p_{\mathrm{hit}}\) win, or a measured weight update.
